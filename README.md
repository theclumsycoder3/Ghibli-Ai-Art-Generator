## 🎨 Description

This is a full-stack **AI Ghibli Art Generator** that transforms text prompts or uploaded images into beautiful Ghibli-style artwork using **Stability AI**.

Frontend is built using **React (Vite)** + **Tailwind**, backend uses **Spring Boot** with **OpenFeign** to communicate with the Stability AI API.

---

## 🚀 Features

- Text → Image Ghibli art generation
- Image → Image artistic transformation
- Multiple Ghibli style options
- Fully responsive (mobile + desktop)
- Fast async generation using backend Feign client

---
